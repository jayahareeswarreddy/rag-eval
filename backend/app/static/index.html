What this is

An AI document assistant does two things: it searches your documents for relevant passages, then writes an answer from them. When the answer is wrong, people blame the writing step — but usually the search step never found the right passage, so the model had nothing to work from.

This tool measures the search step. It is currently indexing the Python standard library, so ask it anything Python can do.

  1. Search — see which passages three different search methods find.
  2. Ask — get an answer where every sentence is checked against its source.
  3. Results — the experiment that found which setup works best.

What do the coloured scores mean?
  • by meaning An embedding score. Understands that “encode binary” relates to base64 even with no shared words. Weak on exact names.
  • by keyword A BM25 score. Nails exact identifiers like get_user_session. Blind to wording it has not seen.
  • combined The fused rank that decided the final order.

The two scores sit on completely different scales — roughly 0.25 versus 12 — which is why they are combined by rank position rather than by adding the numbers. Adding them would let whichever method happened to produce a large number win every time.

Is the answer actually supported?

Every sentence must cite a passage, and each citation is checked against the text it points at. Unsupported sentences get flagged rather than shown as fact.

How the checking works

Each sentence is compared against the passage it cites. If too little of the sentence appears in that passage, it is marked unsupported. The check is blunt on purpose: the alternative is asking the model whether it told the truth, and a model that invented a fact will happily confirm that it did not.

Which setup actually works best?

Building a search system means choosing how to split documents, how big the pieces should be, and which method to search with. Those are usually guesses copied from a tutorial. Here they are measured — every combination, scored against questions with known correct answers.

How to read this table
  • split — how documents were cut up: fixed every N characters, recursive at paragraph breaks, auto at function and heading boundaries.
  • top-1 — how often the single best result was correct. The column that matters most.
  • top-5 — how often the right document appeared anywhere in the top five. Near 1.0 everywhere, so it cannot separate setups.
  • rank score — rewards putting the right answer higher rather than merely including it.

Click any heading to sort. Highlighted rows share the best top-1 score.
